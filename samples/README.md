# Sample images

36 labelled photos from the PlantVillage dataset, CC0 1.0 (public domain), as mirrored at
https://huggingface.co/datasets/DScomp380/plant_village. Two per class, taken at fixed row offsets
so the set can be rebuilt. `manifest.json` holds each image's ground-truth label (`truth`).

Caveat: PlantVillage photos are single leaves on plain backgrounds, which is easier than field photos.
Results on these images will flatter real-world performance.
